## Mô tả dự án
Website Vaccination.ng - Hệ thống đăng ký tiêm vaccine COVID-19

## Công nghệ sử dụng
- NodeJS + ExpressJS
- MongoDB + Mongoose
- Tailwind CSS
- Nodemon

## Cách chạy dự án
1. Clone project về máy
2. Chạy `npm install`
3. Chạy `npm start`
4. Truy cập `http://localhost:3000`
